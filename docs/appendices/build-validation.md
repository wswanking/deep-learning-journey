- 同一书内多图可能复用箭头 ID。现在按图重命名标识符和局部引用，含引号的引用已检查。
- 目录原先叠加了列表编号和小节自带编号，已统一样式。
- 临时 HTML 中的本地附件链接已改写到稳定的最终输出目录，避免引用清理后的临时目录。

## 5. 表格分页回归（2026-11-15）
