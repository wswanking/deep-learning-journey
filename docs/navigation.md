# 章节导航与完成状态约定

> INF-03公共约定，更新日期：2026-11-15。

## 1. 阅读入口与共享附录

仓库README是读者入口，章节计划是完整课程的任务清单，两者承担不同的阅读需要。README的正式教程目录仅列真实存在并已验收完成的章节，按00～30的编号顺序排列。规划中的标题放在章节计划中；有文件但未验收的正文只能标作草稿预览，不混入正式阅读目录。

基础查阅入口保持稳定：

| 需要 | 文档 |
| --- | --- |
| 理解作者如何组织讲解、公式、来源和图 | [写作与排版规范](authoring-guide.md) |
| 查符号、形状和批次转换 | [公共数学符号](appendices/notation.md) |
| 查中文、英文与缩写的对应 | [公共术语表](appendices/glossary.md) |
| 查核验过的教材和大学课程 | [参考来源目录](appendices/references.md) |
| 核对本机实际能力与已知限制 | [环境报告](appendices/environment.md) |
| 构建草稿、单章与全书 | [构建说明](build-guide.md) |

这些附录提供查阅支持，不计入31个正式教程章节。当前已完成章以章节计划实际勾选结果为准，本规则不再维护一份手工进度副本。

## 2. 三处信息的一致性

| 文件 | 记录什么 | 更新时机 |
| --- | --- | --- |
| docs/chapter-plan.md | 全部章节任务、状态、依赖和验收证据 | 开始实现、进入验证、完成验收时 |
| docs/book.json | 已存在正式正文的编号、标题与实际源文件；独立样张另放samples | 实际正文创建后、首次单章构建前 |
| README.md | 已完成教程的阅读链接、公共查阅入口和运行方法 | 每章验收完成时 |

`book.json`登记一章只说明源文件可供构建，不等于完成。默认全书选择器同时要求该章在章节计划中以 `### [x] 00：…` 这样的格式勾选完成，且它已登记到 `chapters` 数组；编号须为两位数字、不得重复，全书按编号升序。章节尚未存在时不登记虚假路径。独立排版样张留在 `samples`，不能因通过排版验收就列作正式章。

## 3. 章内链接与前后章

每章开头提供返回README和章节计划的相对链接，并列出真实的前置知识。上一章、下一章只链接到实际存在且已完成的对应正文。下一章尚未完成时，用文字说明其主题并指向章节计划；不制造悬空文件链接。章节模板中的相对路径必须按正文位于 `docs/chapters/` 的实际位置重写。

代码和图片都使用仓库内相对路径，且与章节编号对应。例如第08章的资源放入 `docs/assets/08-backpropagation/`、实验放入 `examples/08-backpropagation/`；这些是命名约定，不意味着目录已经存在。链接到具体小节时核对构建器生成的真实标题锚点，避免仅凭浏览器的显示文字猜测。

构建器根据本次选入的文档顺序自动生成目录、书签和前后导航。全书中的Markdown链接指向内部正文；未选入输出的本地文档按现有构建规则作为源附件复制，详情见构建说明。只选择一章时，自动导航只包含该章，不代表相邻章节被删除或未完成。跨电脑分享HTML时携带相应的 `sources/` 附件目录。

## 4. 先预览，再验收，最后纳入全书

多章可并行调研、撰写和准备独立实验；各章由明确负责人修改各自文件，避免同时改写共享目录和任务状态。公共符号、前置依赖和引用由协调者统一核对。正式验收、完成标记和代码提交仍按章节编号逐章推进，后写出的章节不能绕过尚未验收的前置章。未验收草稿不得进入正式全书。

每章按以下顺序推进：

1. 在章节计划把当前章标为进行中，创建真实Markdown、SVG及必要实验。
2. 在 `book.json` 登记实际编号、标题和路径；章内页首明确当前状态。
3. 从仓库根目录用 `& ./scripts/build.ps1 -Format all -Chapter 00` 这类单章命令构建。将 `00` 换为当前已登记编号。未完成章会显示“草稿预览”，不需要提前勾选完成才能检查格式。
4. 验证正文、数学维度、来源、实验和本章专属验收；实际查看HTML与PDF的中文、公式、图、表格、代码和分页，检查SVG及PDF矢量保留。
5. 有失败或未验证项时，保留进行中或待验证，并记录具体问题。通过全部标准后再勾选章节完成，补充验证证据、README阅读链接和项目上下文。
6. 重建默认全书，检查完成清单与输出目录一致，然后提交当前章及相关文件。正常快进同步远程的授权与执行遵循项目上下文和用户当前指令。

`-Sample`专用于工具链样张，不能代替真实章节导出验收。没有任何已完成章时，默认全书应明确报错；不能靠把草稿勾选为完成或用样张充数来让构建通过。

## 5. 接续工作时的检查

从正式仓库读取AGENTS、写作规范、章节计划及当前章。核对实际路径、Git远程和未提交修改；在不覆盖已有工作的前提下处理最早未完成且满足前置依赖的章节。完成本章后检查所有新增本地链接、数学渲染和资源路径，再更新状态。阶段性结果不能写成“全书完成”，文档计划也不能当作教程正文。
