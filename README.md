# deep-learning-journey

深入学习-LLM-多模态教程项目。

以《Deep Learning》（花书）为基础，循序渐进学习数学基础、神经网络、典型模型、LLM 和多模态，并结合 Windows 本机开展小模型训练实践。

## 教程要求

核心原理配图文并注明经典教材、大学课程或原始论文来源；所有配图使用真正的矢量图（SVG，PDF 导出保留矢量），保证放大和打印时的清晰度；数学符号规范，推导与概念解释完整；按前置知识逐步推进。章节以 Markdown 为内容源，计划支持一键生成 HTML 和 PDF。
