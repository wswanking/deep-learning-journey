# 第02章实验：解析导数、差分与自动微分

本实验对应[第02章](../../docs/chapters/02-calculus.md)，使用固定解析函数核对导数、梯度、方向导数与非方形Jacobian，并演示不可微点的例外。无需下载数据，不训练模型，不读写模型权重。

## 运行

从仓库根目录调用第00章准备的项目解释器：

```powershell
& ./.venv/Scripts/python.exe -B examples/02-calculus/run.py
```

依赖为NumPy和CPU版PyTorch；本机实际版本Python 3.11.5、NumPy 2.4.6、PyTorch 2.15.0+cpu。脚本显式使用CPU、float64和1个PyTorch线程，不使用随机数。

默认输出为 `build/experiments/02-calculus/results.json`，包含实际版本、时间、配置、解析值、中心差分、自动微分、误差扫描和Windows进程峰值驻留内存。成功后打印 `PASS`；任何数值或形状断言失败都会以错误退出。

```powershell
& ./.venv/Scripts/python.exe -B examples/02-calculus/run.py --epsilon 1e-6 --output build/experiments/02-calculus/h-1e-6.json
```

`--epsilon`需为有限正数；它控制主差分检查，默认 `1e-5`。太大或太小可能导致误差超出设定阈值，不能把任意扰动都视为有效验证。

## 检查内容

| 对象 | 预期结果 |
| --- | --- |
| $`s^2`$ 在2处的导数 | 4 |
| $`x_1^2+2x_2^2`$ 在 $`(1,1)`$ 处的梯度 | $`[2,4]`$ |
| $`(x_1x_2+x_1)^2`$ 在 $`(1,2)`$ 处的梯度 | $`[18,6]`$ |
| 非多项式函数 | 解析表达式、差分、自动微分在给定容差内相符 |
| 沿单位方向 $`(0.6,0.8)`$ 的变化率 | 4.4 |
| 二输入三输出函数的Jacobian | 形状 `(3,2)`，行为输出、列为输入 |
| Jacobian转置组合标量输出 | 输入梯度 $`[8,6]`$ |
| $`\sin(0.7)`$ 的中心差分扫描 | 扰动很小时误差可能重新增大 |
| $`\lvert s\rvert`$ 在0处 | 左差商为 $`-1`$、右差商为1，经典双侧导数不存在；中心差分与框架可以都返回0 |

解析函数及输入为本项目教学构造，不涉及外部数据许可；训练/验证/测试划分、随机种子、优化器及检查点均不适用。本机一次默认运行记录约0.107秒纯计算、1.831秒含导入、197.7 MiB进程峰值驻留内存。这些为单次观察，详细说明见章节正文。
