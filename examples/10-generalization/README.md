# 第10章实验：泛化、权重衰减、Dropout与早停

对应[第10章](../../docs/chapters/10-generalization.md)。用同一份含噪合成回归数据比较3种方法、3个初始化种子，并验证早停最佳模型恢复和同种子重跑。

## 执行

```powershell
& ./.venv/Scripts/python.exe -B examples/10-generalization/run.py
```

从仓库根目录运行，使用项目NumPy与CPU PyTorch。本机Python 3.11.5、NumPy 2.4.6、PyTorch 2.15.0+cpu；float64、1个CPU线程和确定性算法开启。无外部数据下载。

数据种子20261115，输入均匀分布于[-1,1]，目标 `sin(3*x)` 加标准差0.2的高斯噪声；训练/验证/测试为20/128/256个独立样本。模型1→48→48→1，有2497个参数。初始化种子11、22、33；每个种子的3种方法具有完全相同初始权重。

三组为无衰减基线、权重矩阵AdamW衰减0.05、隐藏Dropout0.2。学习率0.01，最大800轮，耐心120、最小改善1e-5；所有偏置不衰减。每轮一个完整训练批次，记录的训练/验证MSE均在eval模式下计算，不含参数惩罚。

## 输出与检查

`build/experiments/10-generalization/results.json` 保存数据哈希、完整曲线、指标、最佳轮、停止轮和资源。`checkpoints/` 保存各运行的验证最佳参数；重新加载后要求预测完全一致。所有预设训练和种子11基线复跑完成后才进入最终测试评价阶段，禁止据测试结果回调配置。

[figures.py](figures.py)依据实际报告生成四幅SVG。加 `--skip-figures` 可只复跑实验，`--output` 可改变报告路径。若数值、哈希、恢复或重跑检查失败，脚本以错误退出；成功打印 `PASS`。

一次本机实测3方法的平均验证MSE为0.06808/0.07447/0.06454，测试为0.11587/0.12691/0.10756。权重衰减本次未改善均值；Dropout较低但只有3种子与单一划分，不作统计显著或普遍优势结论。全部训练和检查约3.851秒，含导入6.959秒，不含SVG生成；输入与目标数组载荷6464字节不是进程总内存，峰值内存未测量。

检查点是本项目自行生成的模型参数，恢复只用于最佳模型前向核对；完整继续训练还需优化器和随机状态。数学、图示、随机性边界与来源见章节正文。
