# 第13章CPU序列实验

从仓库根目录执行：

```powershell
& ./.venv/Scripts/python.exe -B examples/13-sequence-models/run.py
```

环境：Python3.11.5、NumPy2.4.6、PyTorch2.15.0+cpu，CPU、float64、1线程。无数据下载。`--epochs 400`为默认预算，可用其他正整数探索；预算改变后的结果不能继续冒充正文默认运行。`--skip-figures`保留实验结果而不更新SVG。

## 协议

- 数据种子20261115；Uniform[-1,1]独立生成64/32/32条训练/验证/测试序列，每条20步、1输入维。
- 输出回忆四步前的输入，只对第5～20步求平均平方误差，没有额外1/2；前4步不是零标签。
- 三个单层单向模型RNN/LSTM/GRU，隐藏宽度12、线性读出1维；参数193/733/553，预算相同但参数不相同。
- 模型种子17，默认初始化，Adam学习率0.01、betas=(0.9,0.999)、epsilon=1e-8，无衰减，400个全批次更新。
- 每10轮验证，保存最低验证MSE的已记录状态；不早停。完整20步BPTT，梯度全局范数裁剪1。
- 每次独立序列前向从零状态开始；验证/测试使用eval及no_grad。
- 固定三方法训练与RNN复跑结束后才测试，不依据测试结果改配置。

## 输出与实测

`build/experiments/13-sequence-models/results.json`记录数据哈希、曲线、手算及自动微分核对、参数量、最佳轮、最终测试与耗时；`checkpoints/`存各模型验证最佳参数，加载后要求预测完全一致。`figures.py`由报告生成五幅SVG，图13-2为明确条件下的解析机制曲线，图13-5为真实模型结果。
