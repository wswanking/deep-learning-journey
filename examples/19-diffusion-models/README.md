# 第19章二维DDPM实验

从仓库根目录运行：

```powershell
& ./.venv/Scripts/python.exe -B examples/19-diffusion-models/run.py
```

无需下载。Python3.11.5、NumPy2.4.6、PyTorch2.15.0+cpu；CPU、float64、1线程。默认`--updates 2500`；`--skip-figures`只跑数值检查。改变更新预算后应记录新的实际结果，不沿用正文数字。

## 固定协议

- 数据：二维四个等权高斯，中心为(±1.4,±1.4)，各坐标标准差0.2；训练2048/验证512/测试1024，独立生成并存哈希。
- 模型：输入二维加噪点与3维固定时间特征，5→48→48→2，隐藏tanh，共2738参数；跨时间共享。
- 扩散：T64，beta从0.001到0.2线性变化，alpha_bar0=1；直接闭式构造训练加噪，采样使用固定后验方差，t1不加新噪声。
- 优化：Adam lr0.001，betas(0.9,0.999)，eps1e-8，2500更新，batch128；MSE对全部B×2坐标平均，无额外1/2。
- 种子：数据1900/初始化1901/验证噪声1902/训练抽样1903/采样1904/前向链1905/独立真实参照1906。
- 每100步固定验证，恢复验证最优权重；全部配置冻结后才用测试点比较生成分布。一个模型种子不代表完整稳定性研究。

## 实测

2026-11-15 22:59 Asia/Shanghai 默认运行通过。验证最佳2400，噪声MSE0.26393855，已知真实混合分布的解析参照0.25972137，零预测0.98465750。

完整1024点、固定32方向经验投影W1：训练生成0.06852，解析噪声参照生成0.03845，标准高斯0.51312，零噪声预测反向链32.96371，另一批独立真实样本0.08149。有限样本和方向指标不是完整二维距离；独立真实样本的数值并非必须小于当前生成样本，不据此夸大质量。

训练生成四簇计数267/248/244/265，到最近中心平均距离0.27395。零预测链标准差约42，说明没有学到反向去噪时套采样循环会失败。

公式边界、前向均值方差递推、两种后验均值、已知噪声还原、有限梯度、保存恢复、固定种子采样逐项一致均通过。训练与机制3.440秒，单批1024点64步采样0.059秒，完整数值检查3.704秒，含导入7.543秒，不含SVG生成。数据张量载荷57344字节，峰值进程内存未测量。

## 输出

`build/experiments/19-diffusion-models/results.json`记录协议、哈希、曲线、样本、指标和资源；`denoiser.pt`保存验证最佳权重与调度。`figures.py`生成真正SVG：前向展示实际独立增量Markov链，反向展示独立新噪声生成，曲线和散点均来自报告。

这是小型连续二维DDPM教学实验，不是原始图像DDPM复现；调度较粗，起点与高斯反向条件均有近似。解析条件均值参照只因合成分布已知而可用，不能当成未知真实数据的额外标签。
