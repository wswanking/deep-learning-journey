# 第16章：微型Transformer计算检查

从仓库根目录运行：

```powershell
& ./.venv/Scripts/python.exe -B examples/16-transformer/run.py
```

Linux / WSL（先按[Linux环境指南](../../docs/linux-guide.md)准备依赖）：

```bash
.venv-linux/bin/python -B examples/16-transformer/run.py
```

环境为Python3.11.5、NumPy2.4.6、PyTorch2.15.0+cpu，CPU、float64、单线程，种子1601。无下载。`--skip-figures`只运行数值检查而不更新图。

## 明确范围

这是一个600参数Pre-LN block的实现检查：宽8、2头、每头4、FFN宽16、ReLU、Dropout0、LayerNorm epsilon1e-5，无块后额外归一化。输入为2条长度5的固定词元编号，随机嵌入加正弦位置；嵌入64与读出72个参数另计。

未训练、没有优化器和泛化划分，没有语言能力结论。计算一次正确右移的4位置词表交叉熵并反传，用于检查梯度。不是复现完整原始Transformer、BERT或GPT-2。
