# 第20章原创语料

raw.jsonl为本教程原创短句，遵循仓库根LICENSE；没有外部爬取内容。12个family各含3篇同主语不同句式的英文文本：cat/dog/bird/fish/fox/bear/pear/apple/plum/peach/grape/melon。另故意加入2个可规范化去重的副本、空白和1字符短文，共40条。

字段：id为唯一记录名，group_id为预先给定同主题家族，text为原始文档字符串。JSON转义的换行属于原始文本的一部分。原始文件SHA256：

~~~text
9c0ce17ee77193fea99f9ee85c518dc78c0c323ffdcc3726cd88343928c7a712
~~~

corpus.py固定执行NFC、CRLF/CR→LF、去行尾空白/全文首尾空白，按规范化整篇SHA256去重；不足2字节无条件预测对则丢弃。跨声明组的同一精确文本会拒绝，需要先核对来源身份。首次清理后保留36篇。没有自动删除改写或公共模板。

按SHA256(20261115|group_id)排序后8/2/2组划分，不根据测试指标改组。训练24篇971个后续字节，验证6篇239个，测试6篇245个。来源组与整篇哈希无交集，但一般句式模板跨组共享；这是机制教学语料，不代表自然语言独立泛化。

运行会将保留/删除ID、各组、文件指纹、规则及最终JSONL写入build/experiments/20-language-model-pretraining。原始文件不被修改。21章可以借用本章的原始文本或协议，但其训练数据与检查点归21章独立记录；本章不写21的文件。
